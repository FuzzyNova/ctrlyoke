# Troubleshooting

Use this section when a workflow does not start, does not resume, or does not satisfy its validation gates.

## Start here

- [Common errors](/troubleshooting/common-errors)
- [FAQ](/troubleshooting/faq)

## Useful places to inspect

- `.flightpath/logs/` for runtime and hook logs
- `.flightpath/.queue/` for working files and runner state
- `.flightpath/.history/` for per-run output history
