The free tier includes running workflows, custom hooks, the MCP and agent managers, the CLI and MCP server, and the dashboard on the computer ctrlyoke runs on, including when you reach that computer over remote desktop or SSH. Scripted and CI/CD use is allowed too, as long as whoever it runs for is eligible.
