## 3. Field-by-field draft (USPTO Trademark Center)

The new Trademark Center walks through these sections in order. Draft values below; `‹DECIDE›` marks an open decision from §5.

### 3.2 Applicant / owner information

### 3.3 Attorney information

### 3.4 Goods / services + filing basis
Select **two classes**. **Pick the identification from the USPTO ID Manual picker** wherever possible — free-form descriptions add a **+$200/class surcharge** and invite scope mistakes. The drafts below are *search seeds* for the picker, not final text.

**International Class 009 — downloadable software**

- Filing basis: **§1(a) Use-in-Commerce** at release (specimen + first-use dates required — see §1 "What §1(a) needs").

**International Class 042 — SaaS / software services**

> **Why two classes:** the product ships as a **downloadable** VS Code extension/CLI (009) **and** has a **hosted/SaaS** dashboard + future Pro/cloud offering (042). Covering both matches how it's actually distributed. Confirm the SaaS scope with the attorney — if the hosted dashboard is purely local/self-hosted, 042 framing may differ.

> **Scope rule:** you can **narrow** goods/services after filing but **never broaden** them. Err slightly broad-but-honest within what you genuinely intend to offer; don't claim goods you won't ship.

## 4. Fees & timeline (Jan-2025 restructure — verify at filing)

**Government fees:**
- Base application: **$350 per class** (electronic; **using ID Manual descriptions**).
- Surcharges to avoid: **+$200/class** free-form identification; **+$100/class** incomplete fields; **+$200/class** per extra 1,000 chars of free-form text.
- **ctrlyoke, 2 classes, clean (ID Manual): ≈ $700.**
- **§1(a) avoids** the separate Statement-of-Use form + ~$150/class fee that §1(b) would have required — the ~$300 saving behind the decision in §1.

**Attorney (hybrid):** clearance opinion ≈ $300–$1,000; optional flat-fee review/filing ≈ $300–$700. All-in wordmark budget ≈ **$1,500–$2,500**.

**Timeline (clean §1(a)):** examination begins **~6–8 months** after filing → if approved, published for opposition (**30-day** window) → **registration** (no Notice-of-Allowance/Statement-of-Use step, since use is proven upfront). Rough total **~10–14 months** to registration; your trademark *rights* run from your first-use/filing date, so you're protected while it processes.

## 6. Should "Fuzzy Nova" also be a trademark?

**Yes, eventually — but it's a separate, lower-urgency filing; don't bundle or delay `ctrlyoke` for it.**

- **House mark vs product mark:** Fuzzy Nova is the **studio/house brand** spanning multiple products (Nibiru game + ctrlyoke dev tool); `ctrlyoke` is a **product mark**. House marks are worth protecting once the studio identity has traction — but the urgent, going-to-market, already-rebranded-once mark is `ctrlyoke`.
- **A company/trade name is *not* automatically a trademark.** "Fuzzy Nova" is protectable as a mark only to the extent it's used as a **source identifier on goods/services** (e.g. shown as the publisher/brand in the extension and on the sites). It increasingly is — which supports filing.
- **Preliminary knockout (June 28, 2026):** no existing USPTO registration for "Fuzzy Nova" or "fuzzynova" found. Positive signal, but **not** a clearance — a full search is still required. Note `fuzzynova.com` is **squatted/parked**; a held domain creates **no trademark rights**, so it doesn't block a Fuzzy Nova mark (it just means the `.com` isn't easily available; you operate on `fuzzno.com`).
- **Its own clearance risk:** "Nova" is **extremely crowded** in software/tech. "Fuzzy Nova" as a whole may clear, but it needs its **own** knockout + full search — do not assume it's clear because `ctrlyoke` cleared.
- **Different/more classes:** spanning **games** (IC 009 downloadable games / IC 041 entertainment) **and** developer **software** (IC 009/042) likely means more classes → more fees.
- **Recommendation:** finish the `ctrlyoke` filing first. Then run a clearance on "Fuzzy Nova" and, if clean and budget allows, file it as the house mark. Treat it as a fast-follow, tracked here, not a dependency.

## 7. Do you need an LLC before filing? — No

**You do not need to form an LLC (or anything else) before filing the trademark.** US trademarks can be owned by an **individual / sole proprietor**. Filing as **Nathan Hickey (Individual)** is correct and fully valid for a DBA.

- **The LLC question is a business decision, not a trademark prerequisite** — it's about liability protection, taxes, and cleanly holding IP in a company. It does **not** gate the filing, and forming one shouldn't delay locking your `ctrlyoke` **priority date** (especially with a ~6–8-month exam runway ahead).
- **Two clean paths if you do want an LLC eventually:**
  1. **File now as Individual** to lock priority → form the LLC whenever → **assign** the mark to the LLC (routine USPTO assignment recordation, minimal fee). ← *Recommended given the urgency.*
  2. **Form the LLC first**, then file in the LLC's name (avoids a later assignment) — only if formation is quick in your state and you want the entity anyway.
- **Do not** file in the name of a "Fuzzy Nova LLC" that doesn't exist — that misidentifies the owner and can void the application.
- This individual-vs-LLC + assignment question is a 5-minute item for the **same attorney doing clearance** (it touches liability/tax). Bundle it into that conversation rather than blocking on it.

## 8. After filing — don't drop the ball

- Record the **serial number**; monitor status in **TSDR** (`tsdr.uspto.gov`).
- Calendar deadlines: **office action responses (typically 3 months, extendable)**, opposition window, and the **Statement of Use** clock after a Notice of Allowance.
- Ignore/scam-filter all "trademark service" mail that isn't from `@uspto.gov`.
- Once registered + in use, watch the **§8 declaration of use (between years 5–6)** and renewals — out of scope now, note for later.
