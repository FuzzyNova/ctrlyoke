# The hosted dashboard's PWA manifest link and `start_url` have their token redacted

- **Found:** 2026-09-27 by the long-running bug-fix workflow final step (claude-cli, helper agent)
- **Area:** `src/server/CtrlYokeHostedServer.ts` (`buildHtml`, `/manifest.webmanifest` route), `src/server/SecretRedactionMiddleware.ts`
- **Severity:** medium

## Symptom

The hosted page's manifest link and the manifest's `start_url` both carry `token=[REDACTED]`
instead of the real access token. The browser never gets the manifest, and an installed PWA would
open on the 401 page.

Reproduced with the real server under `npx tsx`:

- `GET /?token=<64hex>` contains
  `<link rel="manifest" href="/manifest.webmanifest?token=[REDACTED]" />`.
- Fetching that href returns `401 Unauthorized`.
- Fetching the manifest with the real token returns `"start_url":"/?token=[REDACTED]"`.

## Steps to Reproduce

1. Start the hosted server and open `/?token=<token>`.
2. View the page source: the manifest `href` contains `token=[REDACTED]`.
3. Fetch `/manifest.webmanifest?token=<real token>`: `start_url` contains `token=[REDACTED]`.

## Root Cause

`buildHtml` (`CtrlYokeHostedServer.ts:~1829`) and the manifest builder (`~1954`) embed
`token=<value>` in the server's own output. The `res.send`/`res.json` wrapper in
`installSecretRedactionMiddleware` runs the heuristic credential rule over it and masks the value.
The `res.locals.skipSecretRedaction` opt-out exists for exactly this case (its doc comment
describes the same problem for the standalone shim) and is set for the shim and service worker
(`~826`, `~862`). It is missing from the manifest route (`~900`) and the HTML entry routes
(`/`, `/index.html` at `~965`, and the SPA fallback that serves `buildHtml` output).

## Suggested Fix

Set `res.locals.skipSecretRedaction = true` in the manifest route and in every route that sends
`buildHtml` output. These responses are generated by the server and contain no user data. Add a
test asserting the real token appears in the manifest link and in `start_url`.
