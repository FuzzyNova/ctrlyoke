# FlightPath Logo Placeholder

This directory should contain `icon.png` - the extension icon.

## Requirements

- **Format**: PNG (NOT SVG - VS Code Marketplace doesn't support SVG icons)
- **Size**: Minimum 128x128 pixels (256x256 recommended for retina displays)
- **Background**: Transparent or solid color that works on dark/light themes

## Logo Design Recommendations

### Concept 1: Abstract Flight Path 🛫

A stylized curved arrow or trajectory line suggesting a flight path/journey.

- Gradient from blue to purple (tech feel)
- Curved line with motion blur or speed lines
- Simple, recognizable at 16x16 in status bar

### Concept 2: Rocket + Code 🚀

Minimalist rocket silhouette integrated with code brackets.

- Rocket shape with `{ }` or `< >` incorporated
- Single accent color (electric blue, orange, or green)
- Conveys "automation taking off"

### Concept 3: Compass/Navigation 🧭

A modern compass rose suggesting guided direction.

- Fits the "Take Off" and navigation theme
- North arrow styled as a code cursor or prompt
- Clean geometric design

### Concept 4: Autopilot Symbol ✈️

Abstract autopilot indicator (like aircraft instruments).

- Circular with directional indicator
- Tech/dashboard aesthetic
- Could include subtle "FP" letters

### Concept 5: Prompt Queue Visualization 📋➡️

Stacked rectangles with a play button or forward arrow.

- Represents the queue concept visually
- Sequential/stacked layers with motion
- Suggests automation flow
