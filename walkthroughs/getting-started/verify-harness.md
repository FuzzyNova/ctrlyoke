ctrlyoke does not bundle any AI assistant CLI — it drives one you already have installed
(GitHub Copilot CLI, Claude Code, Codex, OpenCode, Qwen Code, or Google Antigravity).

If none of the supported CLIs are detected, the dashboard shows the exact install command
for each one automatically. Install and authenticate at least one before running a workflow.

Once a harness is ready, select it from the Harness tab or the footer quick picker.
